# AI usage log drafts

One file per session day (`YYYY-MM-DD.md`), drafted by `/ai-log` (Claude Code) or the `ai-log` rule (Cursor)
from the raw capture in `.ai-log/raw/`. Each entry follows the course template fields.

Drafts are not the certified log. The Team Lead reviews a draft, fixes every `TODO (Aiman)`, and then moves
the entry into the root `AI_USAGE_LOG.md`.
